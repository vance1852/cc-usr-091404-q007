# 生物制剂效价复测会审

细胞法效价检测的会审系统：保存实验方法版本、板图、标准品批号、稀释序列、原始读数与
拟合参数，执行确定性四参数逻辑（4PL）曲线拟合，按**当时生效的规则集**判定板有效性，
并以受控的复测会审流程形成批次最终结论。计算和接口均使用 Python 实现，全部历史版本
保存在本地 SQLite 数据库中，任何结论都可回溯到未经修改的原始读数。

## 系统组成

| 模块 | 职责 |
| --- | --- |
| `potency/fitting.py` | 确定性 4PL 拟合（Levenberg-Marquardt，初值由数据导出，零随机性） |
| `potency/metrics.py` | 收敛状态、平行性 F 检验、复孔精密度（RSD）、有效范围、相对效价 |
| `potency/rules.py` | 版本化规则集（R01–R07），输出逐条规则命中记录 |
| `potency/combine.py` | 批次结论组合策略：均值 / 逆方差加权 / 中位数 |
| `potency/special.py` | 不完全贝塔函数与 F/t 分布（纯 Python，不依赖 scipy） |
| `potency/storage.py` | SQLite 持久化（追加式，JSON 列，审计日志） |
| `potency/services.py` | 业务工作流：导入、分析、排除孔、复测审批、结论、追溯 |
| `potency/api.py` | FastAPI 接口（23 个端点） |

## 关键设计

**确定性与可复算**
拟合初值完全由数据确定性导出，阻尼调整规则固定，全程无随机数；每次分析快照当时生效
的规则集与拟合参数。`POST /analyses/{id}/recompute` 按快照重算并逐位比对结果。

**原始读数不可变与重复导入识别**
板导入时对所有原始读数、稀释序列、标准品批号计算 SHA-256 内容哈希；内容一致的重复
导入返回 409 并指向已存在的板。追溯接口逐板重算哈希，任何对原始读数的篡改都会导致
`hash_verified=false`。

**排除孔审计**
排除孔必须登记操作者与理由；系统自动记录排除前后的分析版本与各系列效价差异
（`before_potency` / `after_potency` / `delta_potency`）。排除记录追加式保存，不可修改；
原始读数不受影响。

**复测会审流程**
1. 首轮测定完成后由 SUPERVISOR/QA 锁定首轮结论（`POST /batches/{id}/first-round/lock`）；
2. 锁定后才可申请复测（`POST /batches/{id}/retest-requests`）——申请角色与批准角色
   必须不同，且批准人不能是申请人本人；
3. 锁定后导入新板必须关联**已批准**的复测申请；
4. 最终结论（`POST /batches/{id}/conclude`）按方法版本预先配置的组合策略纳入
   **所有**有效且未被取代的测定 —— 系统不提供挑选入口，从机制上防止只保留有利结果。

**追溯**
`GET /batches/{id}/trace` 输出完整链路：结论 → 测定 → 分析版本（含规则集快照）→
板（含内容哈希核验）→ 排除记录 → 标准品批号 / 方法版本。

## 无效板判定规则（默认规则集，可在方法版本中覆盖）

| 规则 | 内容 |
| --- | --- |
| R01 | 标准品与样品曲线均须收敛 |
| R02 | 响应窗口 \|A−D\| ≥ 0.05 |
| R03 | 拟合优度 R² ≥ 0.98 |
| R04 | 复孔 RSD ≤ 15% |
| R05 | 有效范围（10%–90% 跨度窗口）内稀释水平 ≥ 3 级 |
| R06 | 平行性 F 检验 p ≥ 0.05 |
| R07 | 相对效价及标准误可估计 |

## 运行

```bash
pip install -e .            # 或 pip install numpy fastapi uvicorn
uvicorn potency.api:app --port 8000
# 数据库路径：环境变量 POTENCY_DB_PATH（默认 ./potency.db）
```

## 测试

```bash
pip install -e ".[test]"
pytest                      # 88 个测试：数值、规则、工作流、API 端到端
```

测试数据全部使用确定性合成曲线（正弦扰动代替随机噪声），在任何机器上结果一致；
统计分布函数与 scipy 交叉验证。
